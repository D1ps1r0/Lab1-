• Лабораторна робота №1

• Візуальне моделювання фігур Ліссажу

• Мета роботи

Навчитися працювати з WPF та XAML, використовуючи прив'язку даних, команди та модель для розрахунку гармонічних коливань. Створити інтерактивну програму для побудови фігур Ліссажу.

• Теоретичні відомості

Фігури Ліссажу утворюються під час одночасного гармонічного руху по двох взаємно перпендикулярних напрямках.

Математична модель:

x(t) = Ax · sin(2πfx·t + φx)

y(t) = Ay · sin(2πfy·t + φy)

де:
- Ax, Ay — амплітуди;
- fx, fy — частоти в герцах;
- φx, φy — початкові фази;
- t — час.

Фаза в програмі задається в градусах, а перед обчисленнями переводиться в радіани:

φrad = φdeg · π / 180.

Для дискретної побудови використовується крок часу dt. Методичні вказівки вимагають не менше 20 точок на найшвидший період, тому програма перевіряє це обмеження.

• Архітектура програми

У програмі використано спрощену архітектуру MVVM:

1. Model — `LissajousModel.cs` — виконує математичні розрахунки.
2. ViewModel — `MainViewModel.cs` — зберігає параметри, виконує перевірку введення, формує точки та команди.
3. View — `MainWindow.xaml` — містить інтерфейс і графік.
4. Command — `RelayCommand.cs` — реалізує `ICommand`.

• Алгоритм

1. Ввести Ax, Ay, fx, fy, φx, φy та dt.
2. Перевірити правильність параметрів.
3. Перевести фази з градусів у радіани.
4. Визначити тривалість моделювання.
5. Для кожного моменту часу обчислити x(t) та y(t).
6. Перетворити математичні координати у координати Canvas.
7. Передати точки до `Polyline`.
8. Вивести фігуру Ліссажу.

• Перевірка роботи

У програмі передбачені співвідношення частот:

- 1:1;
- 1:2;
- 2:3;
- 3:4.

Також можна змінювати фазу φy за допомогою повзунка.

Для однакових частот та однакових фаз отримується пряма лінія. При однакових амплітудах і зсуві фаз приблизно 90° може утворюватися коло.

• Висновок

У результаті лабораторної роботи створено WPF-програму для візуального моделювання фігур Ліссажу. Реалізовано математичну модель гармонічних коливань, прив'язку параметрів до інтерфейсу, команди, перевірку введених даних та побудову кривої за допомогою `Polyline`. Досліджено вплив співвідношення частот і фаз на форму фігури.
