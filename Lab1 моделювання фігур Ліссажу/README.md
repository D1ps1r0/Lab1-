• Лабораторна робота №1 — Фігури Ліссажу

Готовий WPF-проєкт для Visual Studio.

• Як запустити

1. Розпакуйте ZIP.
2. Відкрийте `Lab1_Lissajous.csproj` у Visual Studio.
3. Переконайтеся, що встановлено workload **.NET desktop development**.
4. Натисніть `F5` або кнопку ▶ Run.
5. У вікні програми змінюйте Ax, Ay, fx, fy, фази та dt.
6. Для демонстрації використовуйте кнопки `1:1`, `1:2`, `2:3`, `3:4`.

•  Реалізовано

- WPF + XAML.
- `INotifyPropertyChanged`.
- `ICommand` через `RelayCommand`.
- Окремий Model для розрахунку координат.
- Візуалізація через `Polyline`.
- Однаковий масштаб по X та Y.
- Перевірка амплітуд, частот і кроку часу.
- Slider для фази φy.
- Чотири співвідношення частот із методички.
- Програма не повинна аварійно завершуватися при некоректних числових параметрах.

•  Важливо для захисту

Основні частини:
- `Models/LissajousModel.cs` — математична модель.
- `ViewModels/MainViewModel.cs` — параметри, команди, перевірка та підготовка точок.
- `MainWindow.xaml` — інтерфейс.
- `Commands/RelayCommand.cs` — реалізація команди.

Проєкт використовує `net8.0-windows` для сумісності з Visual Studio.
